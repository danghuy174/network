### Changed

- On-demand model loads refuse a `max_model_len` that differs from the decode policy's serving
  profile, and a backend whose `/health` does not report enforcing that profile.

- Standing spot offers bind fee profile 1 in v4 signatures when the finalized runtime exposes
  ready inference credits. Uninitialized, initializing, faulted or unreadable credit state
  refuses publication instead of downgrading the signed fee contract.
- Recover session evidence publication from durable, attempt-bound state after RPC loss. New paid
  session admission waits for publication recovery; existing receipts and acknowledgments remain available.
  Paid TOPLOC admission now requires the durable encrypted audit evidence store. Signer reconciliation
  verifies finalized outcomes or complete mortal expiry before releasing a fence.
  Finalized closed channels retire impossible publication admission retries while retaining audit
  evidence, custody metadata and unresolved signer fences.

- On-demand model profiles classify a prepared checkpoint as dense GDN from its `config.json`
  `model_type` (`qwen3_5`, `qwen3_5_text`), not only from Qwen3.5/3.8 names, and refuse it at
  startup unless it loads on one GPU without expert parallelism. A checkpoint config that exists
  but cannot be read or parsed refuses the profile; an unprepared checkpoint is still checked by
  its finalized architecture before loading.

- Session readiness, admission, force-ack capacity and offers read fresh miner-specific
  calibration at one finalized block, without scanning unrelated calibration jobs.
  Initial calibration and renewal discovery still run in background maintenance.
- The model gate and the qualification worker accept a registered root equal to the checkpoint's
  content root (`content-v1`, D-0535) or its dm-verity root (`verity-v1`), and log which scheme
  matched. Qualification checks the hub's published sha256 table against the governed manifest
  root before any weight byte moves, and checks each file as it streams.

### Added

- Private qualification mode keeps the worker out of public discovery, pins its Ghost mailbox,
  and stops new sessions at authorization expiry while allowing existing sessions to drain.

- Startup and hourly release-policy logs: warnings for newer worker builds or unavailable
  version information, and errors for below-minimum or scheduled-for-deprecation versions.
  Deprecation errors include the deadline and upgrade instructions; checks do not stop work
  or install upgrades.

- Independent TOPLOC replay origin (`src/replay-origin.ts`): the authenticated `POST /prefill` a
  qualified checker serves for CLI positive replay. It shares the miner's turn translation and
  backend call, checks the backend's measured identity, and refuses saturated lanes (#3994).

- Signed OCI cache preparation through the managed controller and qualified replay entrypoint,
  with cancellation, preparation metrics, durable cache holds and offline readonly backend mounts.
- On a runtime with D-0542 capacity reservations, the worker sets its reservation rate to
  `floor(cap / MINER_MAX_CONCURRENT_SESSIONS)` (default 4 sessions, at least 1) on startup and
  when its accepted cap moves, if the stored rate is unset or too large. `0` disables it.

- First versioned `miner-worker` image for `linux/amd64`.
- Operator-authenticated session diagnostics retain the latest 50 failed turns in memory,
  with correlation IDs, stage and elapsed time. Abort logs distinguish the worker deadline,
  a client disconnect and model/session cancellation without retaining request contents.

- Settlement repair for a transcript-less agent `force_settle` that defeated a sealed cooperative
  close. The worker reposts the co-signed tariff checkpoint with the sealed transcript at most once
  per channel. It checks fresh attestation and calibration, dispute and escalation state, and DA
  retention through the extended dispute horizon. A write-once encrypted intent is stored before the
  signer fence, and outcomes are reconciled from the finalized extrinsic. `/session/close` answers
  409 with `repair: "posted"` (never `settled`), and payout is recorded from the terminal finalize event.
- Best-effort timing diagnostics for direct-session retirement and DA publication,
  with public identifiers and no evidence or signature contents.
- Read-only signer-fence collection for legacy workers and finalized chain
  inspection; authenticated same-process recovery retries a proven failure's
  archival without restarting or deleting pending-channel state.
- Native DA fixture evidence survives outer Node cancellation and is retained by
  Compute-Channel CI without changing its failed result or existing deadlines.
- Standard versioned worker release packages include the shared classic/containerd
  verifier and installer. Compose preparation changes only the worker image;
  managed upgrades reuse the existing controller configuration. Release builds
  produce qualification candidates, with immutable publication after review.
- Private candidate qualification worker uses bounded spare miner resources,
  measures pinned checkpoint bytes and quantization metadata before loading,
  and retains independent checker orchestration outside ordinary paid serving.
- Operator-only controller install/upgrade package stages one immutable hybrid
  runtime with Docker-backed proof/DA wrappers, preserves host identity/state,
  and refuses handoff while work, holds or signed recovery remain. Authenticated
  cold monitoring reports version/capability and drain state. Its authenticated
  preparation bridge consumes the query-only checkpoint helper, supports pinned
  Hugging Face-compatible sources and manual checkpoints, and reports bounded
  job progress without admitting inference. Source/CPU package only; publication
  and fresh-GPU acceptance are pending.
- Local `prepare-model` verifies manual checkpoints or resumes a configured immutable
  Hugging Face download before atomic publication, independently of paid sessions.
- Operator-enabled six-hour resident reservations keep a qualified model and its
  occupied slot through idle gaps and Closed child channels. The fixed credential,
  model, policy, miner and slot binding survives recovery; restarts require fresh
  qualification, and existing child deadlines and proof gates stay unchanged.
- Reuse a qualified live model process across at most two independently bounded
  channel leases, with at most one accepting new turns. Another process or a
  controller restart requires fresh qualification.
- Authenticated retirement preparation seals the signed claim and produces proof
  and DA evidence before the existing capacity-gated settlement call.
- One shared miner transaction lane retains nonce ownership through finality.
  An uncertain submission leaves an owner-only, fsynced fence across restarts
  and requires operator reconciliation before further signing.

### Fixed

- Cooperative close can settle the latest acknowledged checkpoint after a rejected
  turn. It verifies the separate full-escrow receipt, publishes only the accepted
  prefix's evidence, and preserves retirement fences across retries.

- Prepare initial and upward recalibration claims inside the signer lane using refreshed
  credentials, bond eligibility and a final chain clock, so discovery and queue delays do not
  overstate sustained capacity. Initial stake top-ups remain separate finalized transactions.

- Offline image import on macOS stages under the resolved temp directory, so the symlinked
  `/var` no longer makes every staged OCI member read as a symlink path.
- `signer-fence-check` explains a failed `settle` candidate. `counterparty_force_settle` names
  the earlier `forceSettle` by another signer that moved the channel out of `Open`. For each
  `Settling` channel it reports whether a transcript is on chain, the challenge end, and whether
  `finalize` would forfeit. The release stays blocked. The inspection deadline is now 15 minutes,
  because the full channel scan took about six on public devnet RPC.

- A turn that fails after its first streamed chunk now ends the stream with one
  `{"type":"error","error":"..."}` line naming the failure, at most 300 characters, instead
  of closing silently. Gateways saw only "missing terminal receipt" (304 in a day across 27
  miners) and could not tell which check failed. The line is unsigned diagnostic text and
  carries no sequence, so it is not part of the signed frame stream.

- Finalized dispatch failures retain their exact transaction, block and call
  identity and are archived before the miner lane resumes. Unknown outcomes
  remain fenced, and turn requests during a fence preserve the live transcript,
  turn counter and encrypted checkpoint.
- Artifact-only controller handoffs verify the complete approved OCI closure and
  bind Docker classic's config/rootfs identity without registry access. Pinned
  proof/DA and optional backend artifact paths, parser-tested local examples and
  candidate release manifests retain identity/state checks. Docker 28 classic and
  intended-GPU installation qualification remain release gates.
- A separate artifact-import CLI supports an existing standing Compose miner's
  worker-only upgrade on classic Docker, retaining its backend, model, keys and
  state. Standing handoff manifests record that scope separately from a new
  loading-controller or Qwen model qualification.

- Fresh controller installs discover absent systemd units from explicit manager state and use the configured RPC for historical recovery checks; manager failures and foreign supervisors still refuse handoff.

- Controller installation can use an approved locally imported image without registry authentication only when its canonical repository digest, actual content ID and descriptor all match; all release, native-runtime and fenced-state checks still run.

- Controller upgrades retain authenticated historical checkpoints when a fresh finalized view proves their exact deployment-bound channel is Closed; changed or unresolved evidence and all active ownership guards still refuse handoff.

- Clear a prepared channel's in-memory retirement marker after successful close,
  preserving the marker while preparation or settlement is incomplete.
- Include the DA publisher, dual licenses and miner-control dependency in the
  runtime image's filtered build context, with Docker checks for required inputs
  and excluded private artifacts.
- Accept finalized monotonic escrow top-ups under the original channel identity,
  SLA and lease deadline. Resident teardown waits for all funded members to be
  finalized Closed and excludes concurrent warm admission.
