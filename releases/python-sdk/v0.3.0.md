  in both public helper families. This breaking correction supplies the runtime's
  required fields without inventing financial defaults.

  calls, query the delegate signer's live session nonce, and preserve wrapper,
  dispatch and circuit-breaker failures. Session query/decode errors propagate;
  only an absent option is reported as no session. Decoded booleans and bounded
