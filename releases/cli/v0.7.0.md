### Added

- `flop faucet request` and devnet wallet enrollment funding send
  `client: "flop-cli/<version>"` to the faucet, for its grant telemetry only.
- `flop gateway renew` runs its paid tools probe for a catalog record that declares
  `conformance_windows.tools` but has no exact passed entry yet, and writes a pass valid for at
  most the declared window. An existing pass's window still takes precedence.

### Changed

- `flop launch claude` and `flop launch codex` read the gateway's public model
  catalog before launching and stop, with the reason and the alternatives, when
  the key's model cannot serve the agent: no tool-call support, or (for Claude
  Code) a maximum output below its 8,192-token cap. A model the catalog does not
  list right now, or a catalog that cannot be read, gives a warning and the
  agent still launches.
- Requires `@flop-labs/sdk` 0.7.1, the first SDK release that forwards the faucet
  `client` label.
