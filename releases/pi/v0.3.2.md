### Fixed

- Bound the Pi AI peer to 1.4.x. Pi AI 1.5 removes the `Type` export used by the Durable
  and memory adapters, so the previous open-ended range could install a host that could
  not load the published package. The packed-consumer smoke keeps resolving the declared
  peer range and importing every public entry point.

### Added

- Bounded devnet credential renewal retains the aggregate parent allowance and
  original conversation bindings, drains before rollover, and keeps cached task
  routing and original-key recovery across Worker restarts. The existing-host
  controller journals publication and has no payer funding operation.
  Rotation preflights native FLOP estimates and the gateway's actual admission floor.

- An explicit bounded native Pi A2A text mode for ready text models, without tool
  declarations, retaining the tool-capability requirement for tool-enabled users.
  Execution mode and token bounds remain pinned to the original admission.

- A private operator-owned devnet A2A authority with hash-only bearer authentication, fixed
  admission grants and concrete FLOP Labs deployment profiles, covered by real Workerd binding tests.

- An opt-in authenticated Pi Durable A2A application example with persistent task admission,
  caller isolation, payload-bound retries and credential-bound lifecycle recovery. The private
  Worker remains the default; deployment, genuine registration and verification remain operator gates.
